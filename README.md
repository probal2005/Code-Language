## 📖 About

**Code Language Studio** is a beautiful web application that allows users to **encode** and **decode** text using the **Caesar Cipher** encryption algorithm.

It features a modern Glassmorphism UI, Dark & Light Mode, file upload/download support, clipboard integration, live statistics, and a fully responsive design.

# 📚 How to Use

## Encode Text

1. Enter your text.
2. Choose the shift value.
3. Click **Encode**.
4. Copy or download the encoded text.

---

## Decode Text

1. Paste the encoded text.
2. Click **Decode**.
3. Copy or download the decoded message.

---

# ⌨ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl + Enter | Encode |
| Ctrl + Shift + Enter | Decode |
